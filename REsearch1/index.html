How this works + setup (.env)

Semantic search: page calls POST /api/semantic on the backend proxy (server.js). The proxy embeds your query with OPENAI_EMBED_MODEL and cosine-ranks listings. No key ever ships to the browser.

Web browse (Zillow etc.): POST /api/browse calls the OpenAI Responses API with the web_search tool on model OPENAI_BROWSE_MODEL (default chatgpt-5.6-luna, fallback gpt-4o). Returns real browsed URLs.

Run it: cp .env.example .env → put your OPENAI_API_KEY in .env → node server.js → open http://127.0.0.1:8787. Without a backend the page still works in local demo mode (keyword + TF-IDF ranking, Zillow button opens zillow.com search).

See .env.example for every variable. .env is gitignored — I could not read yours, so the example documents the full contract.
